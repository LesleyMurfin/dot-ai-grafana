The by-design e2e suite now covers Reliability (R2, R5): a genuine dropped-connection transport failure from the dot-ai stub degrades to the same stable 502 envelope as an HTTP-level upstream error, and an Ask completed with no Grafana datasource configured renders a non-fatal Current with per-datasource "missing" notes instead of failing the page — checked against both the rendered page and the actual POST body Playwright observes leaving the browser.
