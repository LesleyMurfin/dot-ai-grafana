Docs and config PRs now run four mechanical gates (`npm run doc-gates`, and a `pull_request` workflow): an edit to the auto-generated `.config/` directory fails instead of being silently reverted by the monthly regeneration; a load-bearing doc phrase fails unless the symbol implementing it exists outside test files; documented timeouts, character caps, the Grafana pins, plugin metadata and the intent shedding order are compared against values extracted from source at run time rather than hardcoded; and compose images must be pinned by digest. Action SHA pinning and the external link check are warn-only.
