Admin configuration now stores GitOps PR-create settings separately from the no-apply analysis token: `jsonData.gitopsProvider` / `gitopsOwner` / `gitopsRepo` / `gitopsBaseBranch` / `gitopsApiUrl` and `secureJsonData.gitopsPrToken`. Query and Remediate still use only `apiKey` and keep working when GitOps fields are missing or denied. Execute stays off until owner, repo, and a PR-create token distinct from the analysis token are set. This release does not create pull requests or apply to the cluster.
