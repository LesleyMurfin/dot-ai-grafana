Removed a genuinely avoidable `@typescript-eslint/no-deprecated` usage in `src/utils/grafanaStack.ts`: the Observable-vs-Promise duck-typing check on a datasource query result now uses rxjs's `isObservable()` helper instead of directly reading `.subscribe` off the deprecated overloaded `Observable.prototype.subscribe`. Behaviourally identical (verified against real `rxjs.of(...)` observables in `grafanaStack.test.ts`).

The three remaining `@typescript-eslint/no-deprecated` warnings in `src/components/App/App.test.tsx` (`onNavChanged`, `query`, `path`) were investigated and left unchanged: all three are non-optional members of `@grafana/data`'s `AppRootProps<T>` (pinned at 11.4.0), so `App`'s root component — which types its props as the full `AppRootProps` — cannot be rendered without supplying them. There is no non-deprecated way to satisfy the interface; suppressing the warning was intentionally avoided per policy.
