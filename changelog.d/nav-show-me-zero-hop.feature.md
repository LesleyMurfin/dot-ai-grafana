Show-me navigation Asks (e.g. "show me the logs") now resolve in zero dot-ai hops when there is Grafana evidence to point at, and never claim evidence exists when it does not: an explicit error is returned when "Send Grafana evidence" is off, when the Grafana stack read failed, and when the read succeeded but returned nothing with no drilldown links either. When the read returns nothing but drilldown links do exist (a datasource is configured but returned no data for this window), the summary offers those links without claiming Current holds evidence. Diagnosis language (why, error, crash, analyze, and related tokens) always forces the normal dot-ai hop instead of the 0-hop skip. Stacked on the Explore/Drilldown link surface only; no dependency on the firing-alert dashboard links branch.
