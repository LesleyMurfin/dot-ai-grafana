Query and Remediate now find a configured Alertmanager datasource instead of reporting it missing on every install. The lookup asked Grafana's datasource registry for datasources of type `alertmanager` without also asking for datasources that declare no metrics/logs/tracing/annotations/alerting capability — which is exactly how Grafana's built-in Alertmanager datasource describes itself, so it was silently excluded from every result. The lookup now includes it, and Current correctly picks up Alertmanager evidence (silences, alerts, notification status) when the datasource is configured.
