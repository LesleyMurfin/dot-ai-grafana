Query Asks that produce Grafana stack evidence now surface dashboard links for any dashboards Grafana has already attached to firing alerts, both in the Map panel and the "Current" evidence block. Dashboard UIDs are read only from the firing-alert data (never a `/api/search` call), capped at 5 per Ask, and validated against a conservative UID shape before a link is built. When no alerts are firing the Dashboards block is omitted entirely so it never spends budget from the fixed Current/Map char caps.
